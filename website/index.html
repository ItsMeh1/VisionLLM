01 / The workbench

One bench, from first image to finished model.

Import, annotate, train and test without moving between tools. The same workspace holds the library, the canvas and the run.

See the project on GitHub ↗
01

Bring the images

Drop a folder, a camera frame or a single file. Everything lands in one library. Duplicates are skipped.

02

Draw what matters

Boxes for detection, polygons for segmentation, a class for classification. The active tool stays out of the way.

03

Train and try it

Choose a model and a length. Watch real epochs and losses, then score the checkpoint on images held back for you.

02 / Local by design

Your images don’t need a cloud.

Browser storage owns the project. A local engine receives a temporary copy only when training starts. There is no account, no telemetry and no service between you and the model.

03 / Run it

Bring your own machine.

VisionLLM runs locally on Apple silicon or CPU. One browser app, one small Python engine, and the files already on your desk.

  1. 01Install the appnpm install
  2. 02Start the enginenpm run engine
  3. 03Open the workbenchnpm run dev

First time? Set up the Python environment once, then keep this tab for the daily loop.

Quickstart / two terminals 
$ npm install
$ npm run engine # terminal 1
$ npm run dev    # terminal 2
